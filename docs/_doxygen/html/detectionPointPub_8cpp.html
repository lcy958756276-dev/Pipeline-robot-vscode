Detailed Description

检测点分析与 midgoal 生成模块

该文件实现了一个 ROS 节点，用于接收检测点信息、机器人位姿和最终目标点， 并根据检测点和机器人当前位置计算中间目标点 (midgoal)。 功能：

  • 订阅 /cable/odom 获取机器人位姿
  • 订阅 /transformed_detection_info 获取检测点
  • 订阅 finalgoal 获取最终目标点
  • 根据检测点和机器人位姿生成 midgoal 点
  • 发布 midgoal 点供导航使用
