Detailed Description

绕线盘与丝杆系统扭矩计算类

功能：

  • 根据绳索长度计算绕线盘半径
  • 计算绕线盘与丝杆的总质量
  • 计算推力、摩擦力
  • 根据几何关系计算总转矩
  • 输出百分比形式的扭矩
