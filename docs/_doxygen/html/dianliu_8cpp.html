void parseAndPublish ( const std::string &  line)

解析一行TCP数据并发布到对应ROS话题

Parameters
line输入字符串

功能：

  • 解析 c0~c4 五个通道数据。
  • 按照公式转换为实际电流值：
    • c0,c1: 5*value/4095*1.55
    • c2: 5*(value-2048)/2048
    • c3,c4: 5*value/4095*0.155
  • 发布到对应 Float32 话题，并打印日志。
