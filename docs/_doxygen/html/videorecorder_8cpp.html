Detailed Description

使用 FFmpeg 将 QImage 视频帧录制为 H.264 视频文件

功能：

  • 支持 RGB32 图像转 YUV420P
  • 多线程录制，使用队列缓存帧
  • 自动处理编码器缓冲区，保证零延迟
  • 支持 start/stop 控制
