Detailed Description

QNode类实现，用于ROS节点初始化、消息订阅/发布以及与Qt界面的交互。

该文件包含：

  • ROS节点初始化与启动
  • 图像、IMU、odom、激光雷达、传感器等数据的订阅回调
  • 各种控制命令和状态信息的发布
  • 将ROS数据转换为Qt可显示的格式（如QImage）
  • Qt信号发射，用于更新界面
