Detailed Description

中途目标点与最终目标点发布器

功能：

  • 订阅 midgoal、finalgoal 和机器人状态
  • 根据机器人当前位置动态发布 waypoint
  • 管理中途目标队列，并保证按 X 坐标升序发布
  • 在到达最终目标时发布停止信号
