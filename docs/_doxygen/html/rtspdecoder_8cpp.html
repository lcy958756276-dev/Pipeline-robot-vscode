Detailed Description

RTSP 视频流解码类，基于 FFmpeg，实现 QThread 异步解码

功能：

  • 连接 RTSP 视频流
  • 使用 FFmpeg 解码 H.264/H.265 视频
  • 转换为 QImage 并通过信号发送到 UI
  • 自动重连功能
