Detailed Description

负责接收目标点并控制机器人运动

功能：

  • 接收 waypoint 消息
  • 判断机器人当前位置与目标点偏差
  • 发送前进、后退、左右矫正和停止指令
  • 根据偏差判断是否到达目标点并发布状态
