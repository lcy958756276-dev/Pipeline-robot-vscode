Detailed Description

RViz 可视化封装类，用于在 Qt 界面中显示机器人、激光、地图和点云

功能：

  • 在 Qt 的 QVBoxLayout 中嵌入 RViz 渲染面板
  • 初始化 RViz VisualizationManager
  • 添加基础显示层：网格、地图、激光扫描、机器人模型、点云
  • 设置 Fixed Frame 为 odom
