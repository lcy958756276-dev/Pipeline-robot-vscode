\doxysubsection{Detailed Description}
Modbus 通信类实现，用于通过串口控制下位机电机 

功能：
\begin{DoxyItemize}
\item 初始化串口参数
\item 发送 Modbus 指令（写单个寄存器、控制电机前进/后退/停止）
\item 计算 CRC16 校验
\item 提供自动前进、自动后退、停止和禁用线路功能 
\end{DoxyItemize}
