\doxysubsection{Detailed Description}
中途目标点与最终目标点发布器 

功能：
\begin{DoxyItemize}
\item 订阅 midgoal、finalgoal 和机器人状态
\item 根据机器人当前位置动态发布 waypoint
\item 管理中途目标队列，并保证按 X 坐标升序发布
\item 在到达最终目标时发布停止信号 
\end{DoxyItemize}
