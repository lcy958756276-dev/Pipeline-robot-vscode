\doxysubsection{Detailed Description}
RViz 可视化封装类，用于在 Qt 界面中显示机器人、激光、地图和点云 

功能：
\begin{DoxyItemize}
\item 在 Qt 的 QVBox\+Layout 中嵌入 RViz 渲染面板
\item 初始化 RViz Visualization\+Manager
\item 添加基础显示层：网格、地图、激光扫描、机器人模型、点云
\item 设置 Fixed Frame 为 odom 
\end{DoxyItemize}
