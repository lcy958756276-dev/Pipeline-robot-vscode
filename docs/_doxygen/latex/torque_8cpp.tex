\doxysubsection{Detailed Description}
绕线盘与丝杆系统扭矩计算类 

功能：
\begin{DoxyItemize}
\item 根据绳索长度计算绕线盘半径
\item 计算绕线盘与丝杆的总质量
\item 计算推力、摩擦力
\item 根据几何关系计算总转矩
\item 输出百分比形式的扭矩 
\end{DoxyItemize}
