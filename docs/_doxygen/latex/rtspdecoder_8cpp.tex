\doxysubsection{Detailed Description}
RTSP 视频流解码类，基于 FFmpeg，实现 QThread 异步解码 

功能：
\begin{DoxyItemize}
\item 连接 RTSP 视频流
\item 使用 FFmpeg 解码 H.\+264/H.265 视频
\item 转换为 QImage 并通过信号发送到 UI
\item 自动重连功能 
\end{DoxyItemize}
