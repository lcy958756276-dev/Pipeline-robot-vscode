\doxysubsection{Detailed Description}
QNode类实现，用于\+ROS节点初始化、消息订阅/发布以及与\+Qt界面的交互。 

该文件包含：
\begin{DoxyItemize}
\item ROS节点初始化与启动
\item 图像、\+IMU、odom、激光雷达、传感器等数据的订阅回调
\item 各种控制命令和状态信息的发布
\item 将\+ROS数据转换为\+Qt可显示的格式（如\+QImage）
\item Qt信号发射，用于更新界面 
\end{DoxyItemize}
