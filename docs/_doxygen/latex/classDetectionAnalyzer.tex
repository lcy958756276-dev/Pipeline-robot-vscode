\doxysubsection{Detailed Description}
分析检测点并生成 midgoal 点 

该类功能：
\begin{DoxyItemize}
\item 缓存检测点信息，避免重复发布
\item 根据当前机器人位置和最终目标点选择合适的 midgoal 点
\item 发布 midgoal 点供导航模块使用 
\end{DoxyItemize}
